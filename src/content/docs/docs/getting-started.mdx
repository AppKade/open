title: Getting started
description: Find a project and make your first contribution.
---

AppKade Open is a public collection of AppKade-maintained software. Browse the [project catalog](/projects/) for source code, installation instructions and links to GitHub issues.

1. Choose a project with a problem you want to help solve.
2. Read that repository's `README.md` and `CONTRIBUTING.md`.
3. Fork the repo, work on a focused change, and submit a pull request.
4. Follow maintainer feedback. Accepted, merged work can earn publicly verifiable recognition.

To help with this website itself, see [AppKade/open on GitHub](https://github.com/AppKade/open).
