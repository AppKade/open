**Build together. Grow together.**

AppKade Open showcases working open-source projects initiated and maintained by [AppKade](https://appkade.lk). We collaborate through public GitHub issues and pull requests rather than a separate account system.

- [Discover projects](/projects/) and their installation guides.
- [Meet contributors](/contributors/) with evidence-linked work.
- [Check the leaderboard](/leaderboard/) with transparent scoring.
- [Start contributing](/contribute/) to a project.

New projects join the showcase only after they have a real public repository and documentation.
