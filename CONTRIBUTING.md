# Contributing to AppKade Open

Thanks for contributing! Open an issue first for large changes, and keep each PR focused. For local development: Node.js 22.12+, pnpm 10, `pnpm install`, `pnpm test`, `pnpm check`, `pnpm build`.

- Use `main` as the pull request target.
- Do not commit tokens, private emails, personal data or generated build artifacts.
- Add new projects only after their AppKade organization repositories are public and documented.
- Use `type:feature`, `type:fix`, `type:docs`, or `type:test` to categorize merged work, if applicable.
- Link a real issue and describe how reviewers can reproduce or test the change.
- Do not game the scoring by splitting trivial or empty work into multiple PRs.
- Vulnerabilities should follow [SECURITY.md](SECURITY.md), not public issues.

This is community collaboration; inclusion in the recognition list is voluntary. Request corrections or opt-out via repository issues.
