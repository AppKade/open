# Forest Orbit theme

A Gitroom-inspired visual direction adapted to AppKade's original forest-green brand.

## Rules

- Public discovery pages default to dark. Lucode Starlight docs retain independent light and dark modes.
- Keep the exact official AppKade logo when supplied. The text-only header isn't a replacement logo.
- Primary colors: #017737, #5FC27E, #9DDB9F, #6861F2. Background: #0D1711 and #142119. Text: #F2F8F3.
- Do not invent GitHub activity, contributors, badges, or stats. Preserve D1 voting, sync jobs and project IDs.
- Motion is decorative only; respect reduced-motion and keyboard navigation.

## Review

Verify at 360 / 390 / 768 / 1024 / 1440px widths. Check navigation, keyboard access, contrast, dark/light docs, reduced motion, card links, contributor rankings, and D1 votes. Do not merge this visual experiment into main until reviewed.
